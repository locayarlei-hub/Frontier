# Frontier 1.0 Final

Sistema pessoal com Supabase, sem integração paga de IA.

## Módulos
Visão Geral, Projetos/Viagens, Estudos, Veículos, Livros, Finanças, Agenda, Notas, Animais, Alertas, Pesquisa Global e Configurações.

## Novidades da versão final
- edição de projetos, movimentações, compromissos manuais, veículos e livros;
- valores monetários em formato brasileiro (R$ 1.000,00);
- calendário clicável e preferência de início da semana;
- Configurações sincronizadas na conta via metadados do Supabase Auth;
- tema Noite do Texas ou Deserto Claro;
- revisão mobile com navegação inferior;
- PWA instalável em celular/computador;
- mensagens visuais de confirmação.

## Publicação
Mantenha seu `js/config.js` com a Project URL e a Publishable Key do Supabase. O Frontier nunca precisa de uma Secret Key no navegador.

Para GitHub Pages, publique a raiz deste projeto. PWA exige HTTPS, e o GitHub Pages já fornece HTTPS.
